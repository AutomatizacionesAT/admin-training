# Fotos de salas — guía completa

Copia las imágenes, nómbralas como abajo, y ejecuta **`npm run salas:media`** (o reinicia `npm run dev`).

## Reglas rápidas

| Regla | Ejemplo |
|-------|---------|
| Carpeta = sede | `telares/`, `royal/`, `elemento/` |
| Prefijo opcional `Sala ` | `Sala Paris.jpg` |
| Foto 1 | sin número al final |
| Fotos 2 y 3 | `Sala Paris 2.jpg`, `Sala Paris 3.jpg` |
| Salas con número en el nombre | incluir el número: `Sala 201.jpg`, `Sala Laboratorio 1.jpg` |


Verás en consola algo como `· PARIS: 3 foto(s)`. Recarga la app y prueba cada tarjeta.

## Descripciones (opcional)

Solo texto del modal → edita `SALA_DESCRIPCIONES` en  
`src/components/app/Salas/utils/salaMedia.ts`

## Peso y formato

- **WebP o JPG**, ~1280×800 px, **&lt; 300 KB** por foto
- Comprimir en [squoosh.app](https://squoosh.app) antes de subir
